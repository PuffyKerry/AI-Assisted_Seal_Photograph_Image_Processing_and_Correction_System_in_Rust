================================================================================
  CONCLUSIONS
================================================================================

1. ACCURACY: CNN achieves 31.8% lower DCP MSE and 22.3% lower DCP MAE than
   linear regression on the same 1650 query images.

2. MULTI-OUTPUT: CNN additionally predicts CLAHE contrast deficit (MSE 0.0156)
   and brightness deficit (MSE 0.0713), enabling the full DCP → CLAHE → Gamma
   pipeline. The linear regression model can only predict DCP haze score.

3. SPEED: Linear regression is ~5.4x faster (43.18 ms/image vs 235.20 ms/image).
   Both models include the full feature extraction pipeline (DCP computation for
   ground truth labels). The CNN's overhead is due to GPU inference with image
   tiling for large images.

4. REPRODUCIBILITY: All accuracy metrics are perfectly reproducible across trials.
   Speed variance is small (LR: ±1.41ms, CNN: ±13.32ms) with Trial 2 being an
   outlier for CNN (258.93ms vs ~229ms for other trials, likely due to
   background OS activity or GPU thermal throttling).

5. TRADE-OFF: The CNN is the clear choice for quality — it's more accurate on
   the shared DCP task AND provides two additional correction capabilities.
   The ~5x speed penalty (235ms vs 43ms per image) is acceptable for a
   batch processing pipeline where quality matters more than throughput.
